# Mahesvara — S++ (Void)

**Source / inspiration:** *The Irregular at Magic High School* — "Mahesvara", the secret code name of
Tatsuya Shiba (hidden strategic-class magician). Archetype only; not a copy of the character.
**Taken from the archetype:** calm/ruthless genius, all-black gear, magic-casting weapon, the power to
destroy and restore, nullify magic, dispersion (matter dissolving into mist).
**Ours:** ice-blue theme, twin crystal daggers, cracked glass halo, glass wings (awakened form).

**Forms:** base form + awakened (true) form. Planned splash: base and true form back to back (mirrored).

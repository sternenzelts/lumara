# Lumara overview website

Platform: web. Stack: React, Vite, TypeScript, GSAP. Static output, bundled dependencies, relative paths; only Google Fonts is an optional external runtime resource.

This is a separate public overview website for the existing cosmetic gacha retrospective project. Lumara is the world name and remains the temporary public title. The user asked to build this website before returning to the game interface; preserve C:\Users\hp\gacha-retro and the staging interface.

Lumara is a vast fantasy world of plains, seas, mountains and overgrown ruins of a lost advanced civilization. The Dimming extinguished the great beacons. Four nations surround Aurelis, the sky city and Sanctuary. Wardens return to the Sanctuary after each voyage. Fulfilled Vows (team action items) relight its twelve beacons. The game wraps anonymous sprint thoughts, voting, discussion and follow-through in cosmetic character collection. Characters have no influence on votes or discussion.

The latest project brief supplies 13 characters: Mahesvara, Keira, Ayaka, Azrenth, Seren, Ashvane, Suvara, Sollene, Wren, Rook, Calla, Kairo, Dax. Seren, Dawnlight is the mascot and guide. User wrote Selen, but source.md and brief explicitly confirm Seren; retain source spelling until corrected. Kairo has both a standing cutout and a splash.

Art commitment: premium original anime artwork, bright icy blue, ivory, silver, restrained gold. Cinematic website with landscape filling the opening, full-scale mascot, navigable character showcase, world story, and clear retrospective explanation. No sidebar, dashboard cards, copied franchise branding, fabricated launch promises, account actions or downloads.

All assets are local project supplied files except the Lumara world concept generated in this session. Motion is browser camera/parallax and particles, not an AI-generated video or real-time 3D. Accessible keyboard controls, image fallbacks, mobile layout at 375px, explicit motion toggle and reduced-motion support.

Current website scope: an interactive five-region map, a cinematic S++ landscape campaign, all thirteen companion profiles, recorded Japanese voices for the three S++ characters and Seren, and the three-step retrospective explanation. Upcoming fourth S++ and two S+ characters are not invented or published before their assets and details arrive.
